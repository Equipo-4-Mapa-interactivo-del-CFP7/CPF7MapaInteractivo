# CPF7 - Mapa Interactivo Accesible

Proyecto colaborativo orientado al desarrollo de una solución digital accesible e inclusiva para facilitar la orientación física dentro del CFP N.º 7.

## Objetivo

Desarrollar una herramienta que permita a estudiantes, docentes y visitantes orientarse dentro del establecimiento de manera autónoma, contemplando diferentes necesidades de accesibilidad.
