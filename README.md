# 🗺️ CPF7 - Mapa Interactivo Accesible

Proyecto colaborativo orientado al desarrollo de una solución digital **accesible e inclusiva** para facilitar la orientación y navegación dentro del **Centro de Formación Profesional N.º 7**.

La aplicación permite a estudiantes, docentes y visitantes localizar espacios, consultar información y orientarse dentro del establecimiento mediante un mapa interactivo diseñado con foco en accesibilidad y facilidad de uso.

## Objetivo

Desarrollar una herramienta digital que permita a estudiantes, docentes y visitantes:

- Orientarse dentro del establecimiento.
- Localizar espacios y puntos de interés.
- Consultar recorridos y rutas.
- Buscar diferentes sectores del establecimiento.
- Facilitar la orientación considerando necesidades de accesibilidad.
- Utilizar la aplicación desde diferentes dispositivos.
- Acceder a la información mediante una interfaz simple e intuitiva.

El proyecto busca contribuir a una experiencia de navegación **más accesible, autónoma y clara** dentro del establecimiento.

---

## Funcionalidades principales

La aplicación desarrollada contempla:

- Mapa interactivo del establecimiento.
- Visualización de puntos de interés.
- Búsqueda de espacios.
- Navegación mediante rutas.
- Información contextual de los sectores.
- Recursos visuales de apoyo.
- Diseño responsive.
- Consideraciones de accesibilidad.
- Interfaz orientada a una navegación simple e intuitiva.
